# Issue tracker: GitHub

Issues and specs live in GitHub Issues for
`marcodinf-a11y/nowspark`. Use the `gh` CLI for tracker operations.
Infer the repository from the Git remote when working in the clone.

## Conventions

- Publishing to the issue tracker means creating a GitHub issue.
- Fetching a ticket means reading its body, labels, and comments.
- Use docs/agents/triage-labels.md for triage label names.
- For multiline issue bodies and comments, write the text to a
  temporary file and pass it with --body-file.

## Pull requests as a triage surface

PRs as a request surface: no.
