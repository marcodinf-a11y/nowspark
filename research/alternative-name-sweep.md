# Alternative app-name sweep

Checked: 2026-09-15. Candidates: Start Riot, First Spark, NowSpark. Intended product: Android-first procrastination/productivity app with a desktop companion.

## Recommendation

Drop **First Spark** because an exact-name motivation app already exists with closely overlapping features. **NowSpark** and **Start Riot** remain candidates for further investigation, not legally cleared names. On product tone, NowSpark fits a supportive personal app better; that is a naming preference, not a legal risk rating.

## Method and limits

- General exact/spaced-name searches with app, software, company, productivity and trademark terms.
- Site-restricted Google Play and Apple App Store web searches for NowSpark and Start Riot: no clear exact-name app emerged. These were indexed-web searches, not exhaustive native store searches.
- Direct GitHub repository API searches: `nowspark` returned one repository; `startriot` returned zero. A combined `nowspark OR startriot OR firstspark` search returned 44 results, with only the first 30 inspected, largely Spark programming examples. This was not a code-wide or account-name search.
- Registry checks above establish domain registration only.
- See [alternative trademark findings](alternative-names-trademark-check.md) for trademark leads and access limitations, and [Nowvolt sweep](nowvolt-name-sweep.md) for the original candidate.

Before choosing a public brand, complete a live trademark similarity search in intended markets. No name in this report is legally cleared. [DPMA search guidance](https://www.dpma.de/english/trade_marks/trade_mark_search/)
