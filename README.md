# NowSpark

**One small action starts the spark.**

An open-source, Android-first app to help turn an avoided task into a small, doable next action, with a desktop companion for when you're at your computer.

**Status:** Concept stage. Android is the primary platform, with a desktop companion planned. Technology choices are still open.

[Public repository](https://github.com/marcodinf-a11y/nowspark)

## Product direction

- **Phone first:** The main experience belongs on Android, always within reach.
- **Desktop companion:** Support the same purpose at your desk; its exact role is still to be defined.
- **Open source:** Develop in public under the MIT license.

## Proposed first experience

Start with one useful loop:

1. Write down what you're putting off.
2. Choose a next action small enough to start now.
3. Try a short, optional focus session.
4. Record what happened, then continue, shrink the step, or take a break.

These are starting ideas to validate through personal use, rather than a fixed feature list.

## Design principles to explore

- Make starting take less effort than organizing.
- Offer encouragement without guilt or punishment for missed days.
- Keep personal entries private and under the user's control.
- Make the app useful even when motivation is low.

## Next decisions

- Complete the naming checks before investing in branding. **NowSpark** is the chosen project name; the [preliminary naming sweep](research/alternative-name-sweep.md) is not trademark clearance.
- Describe one real procrastination situation the first version should help with.
- Define what the desktop companion needs to do and which desktop systems it should support.
- Choose the implementation approach, storage, and whether cross-device sync is needed.
