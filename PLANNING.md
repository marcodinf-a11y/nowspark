# NowSpark development planning

This document tracks open product and development decisions. The [README](README.md)
introduces NowSpark to prospective users.

## Current state

NowSpark is at the concept stage. No application code or build setup exists yet.
Technology choices are still open.

## Next decisions

- Complete the naming checks before investing in branding. **NowSpark** is the chosen project name; the [preliminary naming sweep](research/alternative-name-sweep.md) is not trademark clearance.
- Walk through a real example of everyday tasks piling up and validate the first experience against it.
- Define what the desktop companion needs to do and which desktop systems it should support.
- Choose the implementation approach, storage, and whether cross-device sync is needed.

Use the [behavioral research foundations](research/nowspark-behavioral-foundations.md)
to inform product experiments and keep evidence separate from design hypotheses.
